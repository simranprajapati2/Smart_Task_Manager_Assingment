# Smart Task Manager

Application built using Next.js, React, Node.js and Express.js.

## Features

- Create new users
- Mock user login
- View all users
- Create tasks
- Edit tasks
- Delete tasks
- Assign tasks to users
- Set task priority
- Set task status
- Add task dependencies
- View My Tasks
- View blocked tasks
- Mark tasks as Done
- Task filtering
- In-memory data storage

## Technology Used

### Frontend
- Next.js
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- CORS

### Database
- In-memory JavaScript Map
